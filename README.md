# SportBridge Global

Premium sports partnerships, pathways, performance and innovation platform.

**Connecting Talent. Technology. Opportunity.**

## Stack

- Next.js 15 (App Router)
- React 19
- Tailwind CSS 4
- Framer Motion
- GSAP / ScrollTrigger
- TypeScript
- Vercel-ready

## Brand

- Background `#08110F`
- Primary `#0E2F2A`
- Gold `#C6A15B`
- Silver `#D9DDE1`
- White `#F8F9FA`
- Typography: Syne (headings) · Manrope (body)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Deploy

Import the repository into Vercel. Next.js is auto-detected.
